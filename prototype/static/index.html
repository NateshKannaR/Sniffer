Graph Structural Insights

Normal Topological Balance:

Normal networks exhibit balanced, predictable in/out degree ratios. Clients talk to gateways and servers with bidirectional data flows.

Port Scan Star Anomaly:

A single node suddenly initiates dozens of high-speed unidirectional edges to multiple ports, breaking the learned graph embedding manifold.

DDoS Influx Bottleneck:

Multiple disparate IPs converge upon a single target server simultaneously, causing an acute in-degree spike.
